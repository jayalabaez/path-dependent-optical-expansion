# Required observational tests

## Non-negotiable successes

A viable alternative must reproduce all of the following with one parameter set:

1. **Supernova event time dilation**
   \[
   \Delta t_{\rm obs}=(1+z)\Delta t_{\rm em}.
   \]
   DES measured a time-dilation exponent consistent with one using 1504 Type Ia supernovae.

2. **Luminosity/angular-distance reciprocity**
   \[
   D_L=(1+z)^2D_A
   \]
   whenever photons follow a metric null congruence and photon number is conserved. Recent SN+BAO/lensing analyses are broadly consistent with the relation, though some high-redshift tests report localized mild deviations that require confirmation.

3. **Radial and transverse BAO**
   The model must predict both the redshift interval and angular size of the same standard ruler. Matching only the supernova Hubble diagram is inadequate.

4. **CMB blackbody and temperature evolution**
   Dissipative photon-energy loss generally distorts the Planck spectrum or changes the temperature-redshift law.

5. **Multimessenger timing**
   Photon and gravitational-wave propagation speeds agree extremely closely at low redshift unless both sectors share the same effective metric. The latter possibility reduces the distinctiveness of an optical-only explanation and shifts constraints to matter couplings.

6. **Achromaticity and coherence**
   No significant frequency-dependent dispersion, line broadening, image blur, or stochastic phase noise may be introduced across astronomical paths.

7. **Polarization**
   Constitutive and metric-affine extensions must satisfy strong birefringence and polarization-rotation limits.

## Interpretation rule

A model that applies the same scaling to photons, gravitational waves, rulers, and clocks may be operationally equivalent to an expanding-frame description. A successful PDOE must either identify a frame-invariant difference or acknowledge that it is a reformulation rather than a new observable theory.
